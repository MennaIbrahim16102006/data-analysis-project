library cafe data analysis project


Project Overview

This project focuses on analyzing Library Cafe data through a complete data analysis workflow, starting with raw data cleaning and ending with an interactive dashboard.

Project Objectives

- Clean and prepare raw data.
- Handle missing and incorrect values.
- Explore and organize the dataset.
- Build an interactive dashboard.

Tools & Technologies

- Python
- Pandas
- NumPy
- Power BI

Project Workflow

1. Data Collection: Obtained the original dataset.
2. Data Cleaning: Used Python to handle missing values, errors, and inconsistent data.
3. Data Preparation: Exported the cleaned dataset.
4. Data Visualization: Created an interactive Power BI dashboard.

Project Structure

- "data/": Original and cleaned datasets.
- "notebooks/": Python data cleaning code.
- "dashboard/": Power BI dashboard.
